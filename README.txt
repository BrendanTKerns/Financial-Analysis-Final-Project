Brendan Kerns and Chi Innis

MAIN SAMPLE
January 1, 2016 through the November 1, 2026 cutoff. November 1 is a
non-trading day. The last observation is October 30, 2026.
MSFT (Information Technology), JPM (Financials), XOM (Energy),
COST (Consumer Staples), JNJ (Health Care).

START HERE
Read Part1_Explanation.pdf from the downloadable package, then open
Part1_Walkthrough.ipynb in Jupyter. A GitHub clone generates the PDF by
running the four Part 1 commands below.
The notebook walks through the calculations with explanations and outputs.
The scripts contain the reproducible implementation used for all five stocks.

SETUP
Use Python 3.12 and a virtual environment. From the repository root:
  python -m venv .venv
  .venv\Scripts\activate
  python -m pip install -r requirements.txt

RUN PART 1
  python scripts/01_get_data.py
  python scripts/02_P1_diagnostics_garch.py
  python scripts/05_figures.py
  python scripts/part1_report.py

The main run uses the supplied price snapshot offline. Explicitly refresh
Yahoo prices, if wanted, with python scripts/01_get_data.py --refresh.
A refresh can change adjusted historical prices and therefore results.
Re-run all subsequent steps after refreshing. The date cutoff stays fixed.
The full five-script project sequence will also include 03_P2_factors.py
and 04_P3_portfolio.py once those parts are implemented.

METHOD CHOICES
ADF with a constant and AIC-selected lag length; KPSS with a constant and
automatic bandwidth. Trend versions also test price and log-price levels.
The GARCH model uses 100 * log(P[t]/P[t-1]), a constant mean, normal
innovations, and robust standard errors. Annualization uses 252 trading days.
The main estimates use all returns. The 1st/99th percentile cap is a
separate sensitivity check. Read the report's limitations before interpreting
p-values, persistence, half-life or long-run variance.
