# Financial Analysis Final Project

Final project for BUS493 at the University of Puget Sound.

## Repository layout

This repository follows the basic notebook-and-folder layout used in [LAI_in_snow](https://github.com/upschemistry/LAI_in_snow).

- `Financial_Analysis.ipynb`: starter notebook for project analysis.
- `GPT/`: space for AI-assisted working files.
- `.gitignore`: excludes temporary system, Python, and notebook files using the same rules as LAI_in_snow.

Add project-specific folders and data as the project develops. The starter notebook contains no data or completed analysis.
