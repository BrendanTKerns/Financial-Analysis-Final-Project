## Part 1 risk and volatility

[Open the executed walkthrough](Part1_Walkthrough.ipynb) for step-by-step explanations and numerical outputs. See [README.txt](README.txt) for setup and run instructions.

Main sample: January 2016 through October 30, 2026, using the assignment's November 1 cutoff.

| Stock | Sample annual volatility | GARCH variance-shock half-life |
|---|---:|---:|
| MSFT | 27.41% | 21.9 trading days |
| JPM | 27.16% | 9.0 trading days |
| XOM | 27.87% | 243.1 trading days |
| COST | 21.84% | 12.0 trading days |
| JNJ | 18.65% | 9.0 trading days |

Half-lives are uncertain estimates. XOM is especially sensitive because persistence is near one, and its residuals retain some volatility dependence. See the guide and saved diagnostics.

The explanation PDF is included in the downloadable Part 1 package provided in the project chat. Running scripts/part1_report.py generates it locally after generating the figures.

### Reproduce Part 1

Install requirements.txt, then run:

```text
python scripts/01_get_data.py
python scripts/02_P1_diagnostics_garch.py
python scripts/05_figures.py
python scripts/part1_report.py
```

The fixed source data are included. An explicit --refresh option downloads updated adjusted prices while keeping the main cutoff. Results, figures, and the PDF are regenerated by these commands.
